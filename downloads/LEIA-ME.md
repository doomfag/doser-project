# Baixar e abrir o Doser

Nesta pasta, abra Doser-offline.zip no GitHub e use o ícone Download raw file. O download é servido pelo GitHub. Extraia o ZIP e abra Doser.html no navegador. Não precisa instalar dependências.

O aplicativo e a base de distribuição estão incluídos. Bulas e links de farmácias precisam de internet. A versão HTML não atualiza a base automaticamente. Favoritos e anotações ficam no navegador e devem ser exportados separadamente.

A calculadora converte apenas doses já prescritas. A cobertura clínica é parcial.
